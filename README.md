Anime Spinner Listing 🎌

A simple Android application that displays a list of popular anime using a Spinner. When the user selects an anime, the application opens a web browser and searches for the selected anime.

📱 Features
Display a list of popular anime using Spinner.
Populate the Spinner using a string-array resource.
Detect the selected anime with OnItemSelectedListener.
Open the selected anime in a web browser.
Search automatically using Google.
Built with Kotlin and Android Studio.
🛠️ Technologies Used
Kotlin
Android Studio
XML
Spinner
ArrayAdapter
Intent
Uri
